# 🎓 Learning Management System (LMS)

An advanced **University-Level Learning Management System** designed to streamline the educational process for students, teachers, and administrators.  
This project won **1st place** among all graduation projects at our university.

---

## 🚀 Features

✅ **Course Content Management** — Upload and organize lectures, PDFs, and past exams by year and subject.  
✅ **AI Assistant** — Summarizes lectures and provides personalized study guidance.  
✅ **Quizzes & Assignments** — Create, auto-grade, and track student progress with detailed analytics.  
✅ **Collaboration Tools** — Real-time forums and chatrooms organized by year and subject.  
✅ **Performance Analytics** — Track student grades, attendance, and overall academic performance.  
✅ **Public Deployment** — The system is deployed online for real-world usability.  

---

## 🛠 Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript , Bootstrap 
- **Backend:** ASP.NET Core (MVC) , (C#) with Entity Framework  
- **Database:** Microsoft SQL Server  
- **Hosting/Deployment:** Monster ASP.NET
- **Real-Time:** Communication: SignalR
